# Рестик

## Запуск

Требуется Node.js 22.13 или новее.

1. Скопируйте `.env.example` в `.env` и задайте `ADMIN_LOGIN` и `ADMIN_PASSWORD`. Если переменные не заданы, используются значения по умолчанию `admin` / `adminpass`. Для интерактивной карты адресов получите ключ JavaScript API Яндекс Карт в [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) и задайте `VITE_YANDEX_MAPS_API_KEY` в `.env`. Этот ключ используется в браузере, поэтому ограничьте его разрешёнными доменами в кабинете Яндекса. Без ключа карта покажет инструкцию по настройке.
2. Запустите сайт и API одной командой: `npm run dev`.

Для отдельного запуска API можно использовать `npm run dev:api`, а для фронтенда — `npm run dev:vite`. Vite проксирует `/api` на локальный сервер. Аккаунты, сессии и пакеты кейтеринга хранятся в SQLite в папке `data` (путь можно изменить через `DATA_DIR`). Для временного прототипа имя, email и телефон профиля дополнительно синхронизируются с публичной коллекцией MockAPI `https://6ae5cbae877d34ccafc2713a.mockapi.io/Profile`; пароли туда не отправляются. Не используйте эту схему с реальными пользовательскими данными: записи коллекции могут быть доступны публично. Пакеты кейтеринга можно добавлять, редактировать и удалять в админ-панели; сайт загружает их из API. Заявки на кейтеринг и бронирования столиков создаются в одной коллекции MockAPI `https://6ae5cbae877d34ccafc2713a.mockapi.io/Reserve` с разными значениями поля `type`; админ-панель отображает их вместе, различая тип заявки. Бронирования столиков из коллекции можно обновлять и отменять там же; ранее сохраненные в SQLite бронирования также отображаются в админ-панели. Новые отзывы загружаются, создаются и удаляются в MockAPI `https://6ae34074933120ae20f887e5.mockapi.io/Reviews`; ранее сохраненные в SQLite отзывы также отображаются в приложении и удаляются из SQLite. Меню и заказы загружаются, создаются и удаляются в MockAPI по адресам `https://6ace15e7f338359cf1c30f66.mockapi.io/menu` и `https://6ace15e7f338359cf1c30f66.mockapi.io/orders`; ранее созданные заказы из SQLite также отображаются в админ-панели. Мастер-классы работают через MockAPI `Master` (также отображаются записи из SQLite). База данных не должна располагаться на временной файловой системе: для production используйте Node-хостинг с постоянным диском, соберите сайт командой `npm run build` и запустите `npm start`.

## Телефонные номера

Во всех формах телефона используется выбор страны и проверка международного номера. В API номер передается и сохраняется в формате E.164, например `+996555123456`; пустые, слишком короткие, слишком длинные и недействительные номера отклоняются.

## Telegram

Регистрация и бронирования работают и без Telegram. Чтобы получать уведомления о новых аккаунтах и бронях столиков, создайте бота через `@BotFather`, получите chat ID (откройте чат с ботом и отправьте ему `/start`) и задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` только в переменных окружения сервера. После этого перезапустите API. Брони сохраняются в MockAPI, а сервер отправляет сведения о дате, времени, количестве гостей, выбранном столике и телефоне клиента в Telegram. Если уведомление не отправлено, страница бронирования покажет предупреждение. Токен нельзя добавлять в `VITE_*` переменные или клиентский код.
