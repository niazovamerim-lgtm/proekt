# Рестик

## Запуск

Требуется Node.js 22.13 или новее.

1. Скопируйте `.env.example` в `.env` и задайте `ADMIN_LOGIN` и уникальный `ADMIN_PASSWORD`.
2. Запустите сайт и API одной командой: `npm run dev`.

Для отдельного запуска API можно использовать `npm run dev:api`, а для фронтенда — `npm run dev:vite`. Vite проксирует `/api` на локальный сервер. Аккаунты, сессии, новые заказы и бронирования хранятся в SQLite в папке `data` (путь можно изменить через `DATA_DIR`). Отзывы сохраняются в MockAPI `Reviews`, мастер-классы — в MockAPI `Master`; ранее созданные записи из SQLite остаются доступны. Новые заказы сохраняются локально; прежние заказы из `VITE_API_URL` также остаются видны в админ-панели. Меню по-прежнему хранится в API из `VITE_API_URL`; переводы названий и описаний сохраняются вместе с блюдом. База данных не должна располагаться на временной файловой системе: для production используйте Node-хостинг с постоянным диском, соберите сайт командой `npm run build` и запустите `npm start`.

## Telegram

Регистрация и список пользователей в админ-панели работают без Telegram. Чтобы получать уведомления о новых аккаунтах, создайте бота через `@BotFather`, получите chat ID и задайте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` только в переменных окружения сервера. После этого перезапустите API. Токен нельзя добавлять в `VITE_*` переменные или клиентский код.
